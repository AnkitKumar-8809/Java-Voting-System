# Java-Voting-System

A simple Java-based Voting System with a Swing GUI and MySQL backend.

##  Features
- Voter login & candidate selection
- Prevents double voting
- Admin panel for results and resetting votes
- Uses JDBC to connect to MySQL

##  Project Structure
- `src/` - Java source files
- `lib/` - MySQL connector JAR
- `pom.xml` - Maven configuration
- `.gitignore` - Ignore `target/`, `.class` files, etc.

##  How to Run
1. Clone the repository.
2. Open the project in NetBeans.
3. Make sure MySQL server is running.
4. Update database credentials in `DBConnection.java`.
5. Run the `VotingGUI.java` or `VotingSwing.java`.
